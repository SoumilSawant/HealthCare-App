HOW A TEAMMATE CAN ADD OR REFRESH THE SAME DATA
------------------------------------------------
1. Ensure the latest SoulPlace backend code containing soulplace/review_seed.py
   is installed in their frappe-bench.
2. Open Terminal and enter their frappe-bench directory.
3. Run:

   bench --site soulplace.localhost execute soulplace.review_seed.seed_review_accounts --kwargs '{"password":"4321"}'

Replace soulplace.localhost if their local Frappe site has a different name.
The command is idempotent: running it again updates these review profiles and
passwords instead of intentionally creating another copy.
