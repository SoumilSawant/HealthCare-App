# Legacy mobile source

This directory preserves the earlier React Native/Expo implementation and its
native configuration. It is retained only as a historical reference while the
supported product is the Vite web application at the repository root.

It is deliberately outside the web TypeScript configuration, dependency graph,
tests, and build output. Do not import code from this directory into `src/`.

Historical setup and implementation notes are in `../../docs/legacy-mobile/`.
